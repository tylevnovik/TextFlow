# TextFlow Studio PRD

## 产品定位

TextFlow Studio 是面向研究、舆情与语料整理场景的桌面优先工作台，提供从原始文本导入、清洗、标准化、切词、规则治理，到基础文本挖掘与报告导出的完整链路。

## V1 核心目标

- 安装即用
- 项目化管理
- 处理流程可复跑
- 规则命中可审计
- 分析结果可导出
- 为未来节点式流程预留 schema

## 目标用户

- 社科、人文、数字人文研究者
- 舆情与评论分析从业者
- 需要标准化文本处理流程但不想写代码的业务用户

## 核心模块

- 项目
- 数据
- 流程
- 词表
- 分析
- 结果
- 报告
- 设置
