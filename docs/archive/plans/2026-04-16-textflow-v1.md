# TextFlow Studio V1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 从空仓库落地一个可运行的 TextFlow Studio V1，包括桌面端、Python 引擎、项目 schema、分析流程和导出能力。

**Architecture:** 采用 monorepo。`apps/desktop` 负责 React + Tauri 界面与桌面桥接，`services/python-engine` 负责项目存储、导入、预处理、分析与导出，`packages/shared-types` 负责共享领域模型。前端通过 bridge 调用 Tauri command，Tauri 再调用 Python 引擎。

**Tech Stack:** Tauri 2, React 18, TypeScript, Vite, Python 3.11+, pandas, scikit-learn, matplotlib, pytest
