# TextFlow Studio UI Spec

## 视觉方向

V1 使用“编辑部仪表台 + 工程工作台”的视觉语气：大标题、浓重分区、纸张质感背景与数据色块并置，强调专业、可审计、桌面工具属性。

## 页面

- 首页：最近项目、新建、模板、打开
- 项目：概览、当前词表、运行历史
- 数据：导入、字段映射、文档预览、筛选搜索
- 流程：各步骤参数、运行控制、中间结果
  - 顶部先按 `处理对象 -> 处理配方 -> 输出包 -> 本次运行摘要` 组织，避免用户在一堆步骤开关里迷路
  - `处理对象` 支持全部资料、按来源/年份/机构/分类筛选、或手动点选文档
  - `处理配方` 使用少量面向目标的预设卡片，复杂参数折叠到高级设置
  - `输出包` 明确区分表格、图表、汇报与完整结果导向
  - 分析步骤内按 `TF-IDF`、`YAKE`、`NMF` 与聚类分组展示说明和参数
- 词表：多词表编辑、导入导出、命中统计
- 分析：频率、趋势、词文档、词年份、共现、聚类、特征词、机构主题
- 结果：结果表、图表、导出、历史 run
  - 图表导出支持高清 PNG、词云、热力图和可选水印
- 报告：HTML 报告预览与生成
- 设置：路径、语言、主题、性能偏好

## 适配

- 宽屏：三栏
- 中屏：右侧面板折叠
- 小屏：纵向堆叠 + 标签切换
