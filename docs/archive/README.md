# 归档文档说明

`docs/archive/` 保存的是历史文档，不再作为当前实现依据。

这些文档仍然保留，是因为它们记录了：

- 产品早期规格草案
- V1 骨架阶段的实现计划
- V2 节点工作流迁移期的设计思路
- 画布和运行时重设计过程中的讨论
